¡¡ Función suma
int ~ suma <| int ~ a, int ~ b |> |:
    return ~ a + b !
:|

¡¡ Función resta
int ~ resta <| int ~ a, int ~ b |> |:
    return ~ a - b !
:|

¡¡ Función factorial (recursiva)
int ~ factorial <| int ~ n |> |:
    if <| equal <| n, 0 |> |> |:
        return ~ 1 !
    :| else |:
        return ~ n * factorial <| n - 1 |> !
    :|
:|
